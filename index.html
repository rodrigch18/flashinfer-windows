FlashInfer for Windows

Install FlashInfer, the kernel library for LLM serving, natively on Windows 10/11, without WSL. A native MSVC + CUDA 13 build with prebuilt wheels and precompiled kernels for RTX 50 series.

Prebuilt wheels (FlashInfer 0.7.3)

WheelContents
flashinfer_pythonFlashInfer Python package with the Windows JIT changes. Any NVIDIA GPU FlashInfer supports; kernels are compiled on first use.
flashinfer_jit_cache_sm120fPrecompiled (AOT) kernels for RTX 50 series (Blackwell, sm_120 family).
flashinfer_jit_cacheMeta package that registers the precompiled kernels.

Built for Windows x64 with torch 2.14.1 (cu132) and the CUDA 13.5 toolkit. The wheels are Python-version independent and are tested with CPython 3.12 and 3.14.

Requirements

  • Windows 10 or 11, x64, with an NVIDIA driver that supports CUDA 13.
  • Visual Studio Build Tools (C++ workload) and a CUDA 13 toolkit: kernels that are not in the precompiled cache are compiled at runtime.
  • Patch the toolkit's cuda.h once with fix_cuda_13_align.py (CUDA 13 headers use an alignment MSVC rejects; see the README).

Install

In a Python 3.12 or 3.14 virtual environment, install PyTorch first, then the Windows FlashInfer wheels. Install them before anything that depends on FlashInfer, so pip does not pull the Linux-only flashinfer-python from PyPI. flashinfer-python, flashinfer-jit-cache and flashinfer-cubin must be the same version.

Checksums and release notes: latest release.

Other GPUs: build from source

For GPUs other than RTX 50 series, flashinfer_python alone is expected to work, because its JIT compiles kernels for the GPU it runs on (only RTX 50 series is tested). Or build all wheels, including a precompiled cache for your GPU, by following the build instructions.

About this fork

  • Reviewable: each release is the official upstream release tag plus exactly one squashed Windows commit (single diff). Linux behavior is identical to upstream.
  • Credits: the Windows changes started from SystemPanic/flashinfer-windows and were audited down to what Windows needs.
  • No admin rights needed: JIT works without symlink privileges or Developer Mode and keeps paths under the 260-character limit.
  • Companion of vLLM for Windows: each release is the FlashInfer version that vLLM release pins.

FAQ

Can FlashInfer run on Windows?

Yes. Upstream FlashInfer supports Linux only. This fork is a native Windows build (MSVC + CUDA 13) that installs with pip and runs directly on Windows 10/11.

Why does pip install flashinfer-python fail or not work on Windows?

The PyPI package is built for Linux: its JIT compilation assumes GCC, symlinks and Linux paths. Install the Windows wheels from this fork's release instead, before anything that depends on FlashInfer.

Which GPUs are supported?

The precompiled kernel cache targets RTX 50 series, the only tested GPU series. On other NVIDIA GPUs FlashInfer supports, flashinfer_python compiles kernels for your GPU on first use, or you can build the wheels from source for your GPU.

Is this an official FlashInfer project?

No. It is a community fork and is not affiliated with or endorsed by the FlashInfer project. Report Windows-specific problems in this fork's issues.
